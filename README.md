# 🎓 Mentoria Cypress — Boas Práticas de Automação Web

Projeto desenvolvido durante a mentoria de **Boas Práticas de Automação de Testes Web com Cypress**.

A proposta da mentoria é partir de uma automação Web simples e, ao longo das aulas, evoluir o código aplicando boas práticas recomendadas pela **documentação oficial do Cypress**.

> **Objetivo:** transformar um teste que funciona em um teste mais confiável, legível e sustentável.

## 🌐 Aplicação utilizada

**ServeRest — Front-end**

https://front.serverest.dev/

### Fluxo inicial utilizado na mentoria

**Cadastro de usuários**

https://front.serverest.dev/cadastrarusuarios

## 🎯 Objetivos da mentoria

Durante a mentoria serão trabalhados conceitos como:

- Boas práticas de automação Web;
- Estruturação de testes Cypress;
- Assertions;
- Retry-ability;
- Sincronização dos testes;
- Evitar esperas arbitrárias;
- Massa de dados;
- Faker;
- `baseUrl`;
- Reutilização de código;
- Custom Commands;
- Organização do projeto;
- Legibilidade e manutenção;
- Code Review de testes automatizados.

A abordagem será principalmente **prática**, evoluindo o mesmo projeto ao longo das aulas.
